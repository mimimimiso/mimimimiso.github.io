lala プライバシーポリシー

最終更新日: 2026年11月22日

lala は、開発者本人だけが使う個人用の音声アシスタントです。一般には配布していません。このページでは、lala が Google のアカウントから受け取るデータの扱いを説明します。

使う Google のデータ

  • Google カレンダー: 予定の読み取りと、開発者が頼んだときの予定の追加・変更・削除
  • Gmail: 開発者が許可した場合に限り、メールの読み取り

どちらも、開発者本人のアカウントのデータだけを使います。

データの使い方

  • データは、開発者が声で頼んだこと(予定を読み上げる、予定を入れるなど)に答えるためだけに使います。
  • 答えを作るために、必要な部分を、会話を処理する AI サービス(Anthropic)と、声を作るサービス(ElevenLabs)に送ります。それ以外の第三者には送りません。
  • データを売ったり、広告に使ったりすることはありません。
  • Google の認証情報(トークン)は、開発者のパソコンの中だけに保存します。

Google API サービスのユーザーデータに関するポリシー

lala が Google API から受け取った情報の使用と、ほかのアプリへの転送は、Google API サービスのユーザーデータに関するポリシー(限定使用の要件を含む)に従います。

アクセスの取り消し

lala へのアクセスは、いつでも Google アカウントの「サードパーティ製のアプリとサービス」から取り消せます。取り消すと、lala は Google のデータを読み書きできなくなります。

変更

このポリシーを変えたときは、このページを更新し、最終更新日を変えます。
